⚙ Setup

The two P1 directories are opened read-only — nothing is written to them, ever. Every sequence's file is hashed once and re-hashed only when its size or timestamp changes, so the check interval is the frequency of the cross-check, not a re-read of every gigabyte. Sequence No., Linename, Subline, FSP and LSP are read out of the P1 files themselves. Paths are validated on the server before saving, and every save is a journal entry. This replaces install_md5check.sh — a new job only needs these fields changed.

Stop P1 md5sum monitoring?

The cross-check stops and the CSV stops updating. Nothing is deleted — the MD5 cache is kept, so pressing Start again picks up where it left off and only re-hashes files that changed meanwhile.
